PART 1: INITIAL SETUP (First Time Only)
================================================================================

Step 1: Clean Docker Environment
---------------------------------
docker-compose down -v
docker system prune -a -f
docker volume prune -f


Step 2: Start Fresh Containers
-------------------------------
docker-compose up -d --build

Wait 60 seconds for PostgreSQL to initialize


Step 3: Run Database Migrations
--------------------------------
# Method 1: Direct SQL execution (Recommended)
docker-compose exec postgres psql -U admin -d skill_connect_db < scripts/init-db.sql

# Method 2: Additional tables
docker-compose exec postgres psql -U admin -d skill_connect_db < scripts/create-additional-tables.sql


Step 4: Verify Database Setup
------------------------------
docker-compose exec postgres psql -U admin -d skill_connect_db -c "\dt"

Should show tables: users, resumes, messages, email_logs, donations, old_age_homes, orphans, subscriptions


Step 5: Verify All Services
----------------------------
docker-compose ps

All containers should show "Up" status

PART 4: TROUBLESHOOTING
================================================================================

Issue: "Cannot connect to server" on signup/login
Solution:
  - Check backend logs: docker-compose logs backend
  - Verify backend is running: docker-compose ps
  - Check database connection: docker-compose exec postgres psql -U admin -d skill_connect_db -c "SELECT 1"
  - Restart backend: docker-compose restart backend


Issue: Resume upload fails
Solution:
  - Check MinIO is running: docker-compose ps minio
  - Check MinIO logs: docker-compose logs minio
  - Verify MinIO is accessible: curl http://localhost:9000
  - Check file size is < 5MB
  - Check file is PDF/DOCX/DOC


Issue: Emails not sending
Solution:
  - Check Mailpit is running: docker-compose ps mailpit
  - Check backend email config: docker-compose exec backend printenv | grep MAIL
  - Check backend logs for email errors: docker-compose logs backend | grep -i mail
  - Verify Mailpit is accessible: http://localhost:8025


Issue: Database tables not found
Solution:
  - Verify tables exist: docker-compose exec postgres psql -U admin -d skill_connect_db -c "\dt"
  - If missing, run migrations again:
    docker-compose exec postgres psql -U admin -d skill_connect_db < scripts/init-db.sql
    docker-compose exec postgres psql -U admin -d skill_connect_db < scripts/create-additional-tables.sql


Issue: Port already in use
Solution:
  # Windows
  netstat -ano | findstr :3000
  taskkill /PID [PID] /F
  
  # Linux/Mac
  lsof -ti:3000 | xargs kill -9

PART 8: DATABASE SCHEMA
================================================================================

USERS TABLE
  - id (UUID)
  - email (VARCHAR)
  - fullname (VARCHAR)
  - password (VARCHAR hashed)
  - company (VARCHAR)
  - dob (DATE)
  - city (VARCHAR)
  - state (VARCHAR)
  - country (VARCHAR)
  - phone (VARCHAR)
  - status (VARCHAR: employed, graduated, pursuing)
  - qualification (VARCHAR)
  - branch (VARCHAR)
  - passoutyear (VARCHAR)
  - profile_image_url (VARCHAR)
  - bio (TEXT)
  - is_premium (BOOLEAN)
  - is_logged_in (BOOLEAN)
  - created_at (TIMESTAMP)
  - updated_at (TIMESTAMP)

RESUMES TABLE
  - id (UUID)
  - email (VARCHAR)
  - name (VARCHAR)
  - resume_data (TEXT)
  - resume_filename (VARCHAR)
  - file_type (VARCHAR)
  - file_size (INTEGER)
  - file_url (VARCHAR) - MinIO URL
  - created_at (TIMESTAMP)
  - updated_at (TIMESTAMP)

EMAIL_LOGS TABLE
  - id (UUID)
  - recipient_email (VARCHAR)
  - subject (VARCHAR)
  - body (TEXT)
  - status (VARCHAR: sent, failed, pending)
  - error_message (TEXT)
  - sent_at (TIMESTAMP)
  - created_at (TIMESTAMP)

MESSAGES TABLE
  - id (UUID)
  - sender_id (UUID)
  - receiver_id (UUID)
  - content (TEXT)
  - is_read (BOOLEAN)
  - created_at (TIMESTAMP)

DONATIONS TABLE
  - id (UUID)
  - donor_email (VARCHAR)
  - donor_name (VARCHAR)
  - amount (NUMERIC)
  - currency (VARCHAR)
  - category (VARCHAR: old-age-home, orphan, medical)
  - status (VARCHAR: pending, completed, failed)
  - transaction_id (VARCHAR)
  - created_at (TIMESTAMP)

OLD_AGE_HOMES TABLE
  - id (UUID)
  - name (VARCHAR)
  - description (TEXT)
  - address (TEXT)
  - city (VARCHAR)
  - state (VARCHAR)
  - phone (VARCHAR)
  - email (VARCHAR)
  - residents_count (INTEGER)
  - image_url (VARCHAR)
  - created_at (TIMESTAMP)

ORPHANS TABLE
  - id (UUID)
  - center_name (VARCHAR)
  - description (TEXT)
  - address (TEXT)
  - city (VARCHAR)
  - state (VARCHAR)
  - phone (VARCHAR)
  - email (VARCHAR)
  - children_count (INTEGER)
  - image_url (VARCHAR)
  - created_at (TIMESTAMP)

SUBSCRIPTIONS TABLE
  - id (UUID)
  - user_email (VARCHAR)
  - plan_name (VARCHAR: basic, pro, premium)
  - amount (NUMERIC)
  - status (VARCHAR: active, inactive, cancelled)
  - start_date (DATE)
  - end_date (DATE)
  - renewal_date (DATE)
  - created_at (TIMESTAMP)
