PHASE 1: BACKEND INFRASTRUCTURE FIXES
===============================================================================

1. MinIO Upload Fix (Resume, Images, QR Codes)
   - File: /backend/routes/users.js
   - Issue: Resume upload returns "failed to upload"
   - Solution: Use uploadBuffer() instead of uploadFile() for express-fileupload
   - Implementation:
     * Read file from req.files[].data (buffer)
     * Pass to uploadBuffer() with proper contentType
     * Store URL in PostgreSQL resume table
     * Return URL in response

2. SendPulse Email Integration
   - File: /backend/utils/emailService.js (ALREADY IMPLEMENTED)
   - Features:
     * Max 300 users per month
     * Max 12,000 emails per month
     * Automatic limit checking before sending
     * Fallback to Mailpit for local testing
   - Configure in docker-compose:
     * SENDPULSE_USER: your-email@sendpulse.com
     * SENDPULSE_PASS: your-api-key
   - Call: sendEmail(to, subject, htmlContent, userId)

3. PostgreSQL Schema Updates
   - New tables needed:
     * email_logs (track email sending for limits)
     * user_messages (real-time chat storage)
     * user_connections (track who user can message - max 5 free)
     * admin_notifications (messages from admin to users)

4. Real-Time Messaging with PostgreSQL Polling
   - Frontend polls /api/messages/:senderId/:receiverId every 3 seconds
   - Backend fetches from user_messages table
   - Store: sender_id, receiver_id, message_text, created_at, is_read
   - Limit: Free users can chat with max 5 other users

DATABASE SCHEMA ADDITIONS
===============================================================================

-- Email logs table
CREATE TABLE email_logs (
  id SERIAL PRIMARY KEY,
  user_id INTEGER REFERENCES users(id),
  recipient_email VARCHAR(255),
  subject VARCHAR(255),
  service VARCHAR(50), -- 'sendpulse', 'mailpit', 'minio'
  status VARCHAR(50) DEFAULT 'sent',
  created_at TIMESTAMP DEFAULT NOW()
);

-- Real-time messages table
CREATE TABLE user_messages (
  id SERIAL PRIMARY KEY,
  sender_id INTEGER REFERENCES users(id),
  receiver_id INTEGER REFERENCES users(id),
  message_text TEXT,
  is_read BOOLEAN DEFAULT FALSE,
  created_at TIMESTAMP DEFAULT NOW()
);

-- User connections (for limiting free tier)
CREATE TABLE user_connections (
  id SERIAL PRIMARY KEY,
  user_id INTEGER REFERENCES users(id),
  connected_with_id INTEGER REFERENCES users(id),
  status VARCHAR(50) DEFAULT 'pending', -- 'pending', 'accepted', 'rejected'
  created_at TIMESTAMP DEFAULT NOW(),
  UNIQUE(user_id, connected_with_id)
);

-- Admin notifications
CREATE TABLE admin_notifications (
  id SERIAL PRIMARY KEY,
  user_id INTEGER REFERENCES users(id),
  admin_id INTEGER REFERENCES users(id),
  title VARCHAR(255),
  message TEXT,
  is_read BOOLEAN DEFAULT FALSE,
  created_at TIMESTAMP DEFAULT NOW()
);

-- Donations
CREATE TABLE donations (
  id SERIAL PRIMARY KEY,
  user_id INTEGER REFERENCES users(id),
  amount DECIMAL(10, 2),
  donation_type VARCHAR(50), -- 'home', 'orphan', 'general'
  entity_id INTEGER, -- ID of home/orphan
  payment_screenshot_url VARCHAR(500), -- MinIO URL
  status VARCHAR(50) DEFAULT 'pending', -- 'pending', 'confirmed'
  created_at TIMESTAMP DEFAULT NOW()
);

-- Old age homes
CREATE TABLE old_age_homes (
  id SERIAL PRIMARY KEY,
  name VARCHAR(255),
  location VARCHAR(255),
  description TEXT,
  image_url VARCHAR(500), -- MinIO URL
  donation_qr_url VARCHAR(500), -- MinIO URL
  total_residents INTEGER,
  created_at TIMESTAMP DEFAULT NOW()
);

-- Orphans
CREATE TABLE orphans (
  id SERIAL PRIMARY KEY,
  name VARCHAR(255),
  age INTEGER,
  story TEXT,
  image_url VARCHAR(500), -- MinIO URL
  donation_qr_url VARCHAR(500), -- MinIO URL
  status VARCHAR(50) DEFAULT 'active',
  created_at TIMESTAMP DEFAULT NOW()
);

SENDPULSE SETUP INSTRUCTIONS
===============================================================================

1. Create Account at sendpulse.com
2. Get API Credentials:
   - Login → Settings → SMTP
   - Copy SMTP Username (email)
   - Copy SMTP Password (API key)

3. Add to docker-compose.yml:
   environment:
     SENDPULSE_USER: your-email@sendpulse.com
     SENDPULSE_PASS: your-api-key-here
     SENDPULSE_SMTP_HOST: smtp.sendpulse.com
     SENDPULSE_SMTP_PORT: 587

4. Test Email Sending:
   curl -X POST http://localhost:5000/api/test-email \
     -H "Content-Type: application/json" \
     -d '{"email":"test@example.com"}'
