PART 3: HOW EMAILS ARE SENT IN THE APPLICATION
================================================================================

SIGNUP EMAIL FLOW
------------------
1. User fills signup form and clicks "Create Account"
2. Frontend sends POST /api/signup with user data
3. Backend:
   - Validates input
   - Hashes password
   - Inserts user into database
   - Calls sendSignupEmail(email, name)
4. Email service:
   - Creates HTML email template
   - Sends via Mailpit SMTP
   - Logs to email_logs table
5. Mailpit captures email
   - View in http://localhost:8025
   - Email appears in inbox

CODE EXAMPLE:
```javascript
// In auth.js after successful signup
const { sendSignupEmail } = require('../utils/emailService');

try {
  const result = await pool.query(query, values);
  const newUser = result.rows[0];
  
  // Send welcome email
  await sendSignupEmail(newUser.email, newUser.fullname);
  
  res.status(201).json({ success: true, user: newUser });
} catch (err) {
  // Error handling
}
```


DONATION EMAIL FLOW
--------------------
1. User completes donation form
2. Frontend sends POST /api/donation
3. Backend:
   - Validates donation data
   - Processes payment
   - Inserts donation record
   - Sends receipt email
4. Email service creates receipt with:
   - Transaction ID
   - Amount
   - Category
   - Beneficiary info
5. User receives email confirmation


PASSWORD RESET FLOW
-------------------
1. User clicks "Forgot Password" on login page
2. User enters email
3. Backend:
   - Generates reset token
   - Creates reset link: /reset-password?token=xxx
   - Sends email with link
4. User clicks link
5. User sets new password
6. System sends confirmation email

PART 6: DATABASE EMAIL LOGGING
================================================================================

All emails are logged in email_logs table:

Schema:
```sql
CREATE TABLE email_logs (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  recipient_email VARCHAR NOT NULL,
  subject VARCHAR,
  body TEXT,
  status VARCHAR DEFAULT 'pending', -- pending, sent, failed
  error_message TEXT,
  sent_at TIMESTAMP,
  created_at TIMESTAMP DEFAULT NOW()
);
```

Query Examples:

View all sent emails:
```bash
docker-compose exec postgres psql -U admin -d skill_connect_db \
  -c "SELECT recipient_email, subject, status FROM email_logs ORDER BY created_at DESC;"
```

View failed emails:
```bash
docker-compose exec postgres psql -U admin -d skill_connect_db \
  -c "SELECT recipient_email, subject, error_message FROM email_logs WHERE status='failed';"
```

View emails for specific user:
```bash
docker-compose exec postgres psql -U admin -d skill_connect_db \
  -c "SELECT * FROM email_logs WHERE recipient_email='user@example.com';"
```

PART 9: PRODUCTION EMAIL SETUP
================================================================================

For production, replace Mailpit with real SMTP service:

Option 1: SendPulse (Configured in .env.example)
```
SENDPULSE_HOST=smtp.sendpulse.com
SENDPULSE_PORT=587
SENDPULSE_USER=your_email@sendpulse.com
SENDPULSE_PASS=your_password
```

Option 2: Gmail SMTP
```
GMAIL_HOST=smtp.gmail.com
GMAIL_PORT=587
GMAIL_USER=your_email@gmail.com
GMAIL_PASS=app_password (not regular password)
```

Option 3: AWS SES
```
AWS_SES_REGION=us-east-1
AWS_SES_ACCESS_KEY=your_key
AWS_SES_SECRET_KEY=your_secret
```

To switch: Update /backend/utils/emailService.js transport configuration

PART 10: TROUBLESHOOTING EMAIL ISSUES
================================================================================

Issue: Emails not appearing in Mailpit
Solution:
  1. Check Mailpit is running: docker-compose ps mailpit
  2. Check backend logs: docker-compose logs backend | grep -i mail
  3. Verify SMTP connection: docker-compose exec backend curl telnet mailpit:1025
  4. Check emailService.js is initialized
  5. Restart Mailpit: docker-compose restart mailpit


Issue: "Failed to send email" error
Solution:
  1. Check Mailpit SMTP port is 1025: docker-compose logs mailpit | grep 1025
  2. Check environment variables: docker-compose exec backend printenv | grep MAIL
  3. Verify transport configuration in emailService.js
  4. Check email format is valid


Issue: HTML formatting broken in emails
Solution:
  1. Check email template HTML syntax
  2. Verify CSS is inline (Mailpit may strip external CSS)
  3. Test with simple template first
  4. Use HTML email validator


Issue: Emails sent but not showing in logs
Solution:
  1. Verify email_logs table exists: docker-compose exec postgres psql -U admin -d skill_connect_db -c "\dt email_logs"
  2. Check INSERT query in emailService.js
  3. Verify database connection
  4. Check if logging is enabled

PART 11: EMAIL SERVICE API
================================================================================

Core Functions Available:

1. sendSignupEmail(email, name)
   Purpose: Send welcome email after signup
   Usage: await sendSignupEmail('user@example.com', 'John Doe')
   Returns: { success: boolean, messageId: string, error?: string }

2. sendPasswordResetEmail(email, resetLink)
   Purpose: Send password reset link
   Usage: await sendPasswordResetEmail('user@example.com', 'http://localhost:3000/reset?token=xxx')
   Returns: { success: boolean, messageId: string, error?: string }

3. sendDonationReceipt(email, amount, category)
   Purpose: Send donation receipt
   Usage: await sendDonationReceipt('user@example.com', 500, 'old-age-home')
   Returns: { success: boolean, messageId: string, error?: string }

4. sendAdminNotification(adminEmail, message)
   Purpose: Send notification to admin
   Usage: await sendAdminNotification('admin@skillconnect.com', 'New donation: $500')
   Returns: { success: boolean, messageId: string, error?: string }
