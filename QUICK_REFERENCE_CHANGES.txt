DATABASE TABLES STRUCTURE
=====================================================

USERS TABLE (updated):
- id (primary key)
- email (unique)
- fullname
- company (NEW)
- profile_image_url (NEW - MinIO)
- phone, city, state, country
- qualification, branch, passout_year
- status (employed, pursuing, graduated)
- subscription_status (free, premium)
- created_at, updated_at

RESUMES TABLE (new):
- id (primary key)
- email (foreign key)
- resume_filename
- file_type (pdf, docx, doc)
- file_size
- file_url (MinIO URL)
- resume_data (extracted text)
- created_at, updated_at

SUBSCRIPTIONS TABLE (new):
- id (primary key)
- user_id, email (foreign key)
- plan_id
- payment_screenshot_url (MinIO)
- transaction_proof
- status (pending, active, rejected)
- start_date, end_date
- created_at, updated_at

OLD_AGE_HOMES TABLE (new):
- id (primary key)
- name, location, description
- image_url (MinIO)
- qr_url (MinIO)
- contact_phone, contact_email
- created_at

ORPHANS TABLE (new):
- id (primary key)
- name, location, description
- image_url (MinIO)
- qr_url (MinIO)
- contact_phone, contact_email
- created_at

DONATIONS TABLE (new):
- id (primary key)
- donor_name, donor_email, donor_phone
- amount, type (old-age, orphan)
- item_id, item_name
- payment_screenshot_url (MinIO)
- status (pending, confirmed)
- created_at

NOTIFICATIONS TABLE (new):
- id (primary key)
- user_id (foreign key)
- title, message
- category, status
- created_at

SUBSCRIPTION_PLANS TABLE (new):
- id (primary key)
- name (Basic, Premium, Pro)
- price, duration_months
- max_conversations, max_resumes
- priority_support
- created_at

EMAIL SERVICE IMPLEMENTATION
=====================================================

Development (Mailpit):
- Catches all emails at http://localhost:8025
- No setup needed, runs in Docker
- SMTP: localhost:1025
- Preview emails in UI

Production (SendPulse):
- Max 12,000 emails/month
- Max 300 active users
- If users > 300: Don't send more emails
- Create email templates:
  * Welcome Email
  * Subscription Approved
  * Subscription Rejected
  * Donation Receipt
  * Notification from Admin

Implementation:
const sendEmail = async (to, subject, html) => {
  // Check user count
  const userCount = await db.query('SELECT COUNT(*) FROM users');
  if (userCount > 300) {
    console.warn('User limit exceeded. Email not sent.');
    return;
  }
  
  // Send via Mailpit/SendPulse
  await transporter.sendMail({
    from: 'noreply@skillconnect.com',
    to,
    subject,
    html
  });
};
